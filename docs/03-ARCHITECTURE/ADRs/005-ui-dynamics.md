# ADR-005: UI Responsiveness & Dynamics

**Status:** Accepted  
**Date:** 2026-08-10

## Decision

- Optimistic updates (TanStack Query)
- Virtualized lists for large source groups
- Progressive disclosure + sticky section nav
- Keyboard navigation + command palette
- Copy-on-click for all values
- Dark/light theme from day one
- Mobile: bottom sheets, responsive grids
- Import UI must show detected format + parse warnings

UX must feel instant for local interactions while provenance remains visible.
